# 具身智能赛事知识图谱 · 重组原则与使用说明

## 一、核心理念：先习而后学，赛事牵引

本知识图谱的构建遵循「先习而后学」的教学次序，彻底打破「学完六本书才能参赛」的传统路径。

**传统路径（被否定）**：先学完《人工智能概论》《自主智能系统基础》《机器学习方法与应用》《智能机器人与具身智能》《生成式人工智能》《自动驾驶理论、算法与实践》六本教材的全部知识，然后才去参加中国智能车未来挑战赛（IVFC2026）和蚂蚁灵波具身大模型挑战赛。

**本图谱路径（被确立）**：先明确参赛目标（两个赛事的赛题与评分口径），从赛事所需的能力出发，反向拆解出需要学习的知识，再回到六本教材中精准选取对应知识模块。参赛是「习」的起点，知识学习是「习」中发现问题后的「学」的回应。

这一重组原则源自两篇教学原则文章：
- 《先习而后学——AI时代教学次序与教学本质的再思考》：AI 时代的「习」应主动将自己抛入未知的真实场景与复杂约束，先动手、在「跑不通、控不住」的体验中发现知识盲区、产生求知需要，再引入理论。
- 《把教师的学习过程带进课堂》：教学核心是展示如何离开舒适区、从头学习新知识；考核要看见学习过程——依据什么选择、验证了什么、怎样修改，而非只验收最终成果。

## 二、MECE 重组原则

知识体系按 MECE（相互独立、完全穷尽）原则重组，形成「赛事目标 → 能力域 → 知识模块」的三级结构：

1. **赛事目标层**：明确每个赛事的赛题、平台、评分口径、能力要求。两个赛事相互独立，各自牵引一套能力需求。
2. **能力域层**：将赛事所需能力按 MECE 划分为若干能力域。能力域之间不重叠、不遗漏，覆盖参赛所需的全部能力。
3. **知识模块层**：每个能力域对应六本教材中的若干知识模块。知识模块是最小学习单元，可独立学习、独立检验。

在六本教材之上，另设**编程基础与系统交付能力域（能力域9）**，承载朱宗晓具身智能编程教学体系《面向具身智能的编程基础》（详见 `02-教材精华/面向具身智能的编程基础.md`）。它不是第六本教材之外的第七本，而是所有赛事能力落地的**编程地基**：六本教材解决「智能系统怎么做」，编程基础解决「程序怎么写对、写好、集成、交付」。两者构成「编程地基 + 智能系统」的完整能力链。

MECE 的关键约束：
- **相互独立**：同一层级的各能力域/知识模块之间没有交叉，一个知识点不归属于两个并列的域。
- **完全穷尽**：赛事所需的全部能力都能被能力域覆盖，六本教材的精华知识都能被知识模块覆盖。
- **可扩展**：能力域与知识模块均预留「新赛事接口」——当出现新赛事时，在能力域层新增能力域、在知识模块层新增对应知识模块，挂接到已有知识节点上，无需推倒重建。

## 三、六本教材的定位

六本教材不是按顺序逐本学习的「课程表」，而是按赛事能力需求调用的「知识库」。每本教材在图谱中的角色：

| 教材 | 在赛事知识图谱中的角色 |
|---|---|
| 人工智能概论 | 提供智能、知识表示、搜索求解、推理、机器学习与大模型等智能基础理论，是所有赛事能力的「理论底座」 |
| 自主智能系统基础 | 提供感知—决策—控制闭环、反馈理论、自主系统架构，是具身系统与智能车系统的「系统架构依据」 |
| 机器学习方法与应用 | 提供机器学习数学基础、经典算法、深度学习、强化学习，是算法能力的核心来源 |
| 智能机器人与具身智能 | 提供机器人学、感知传感、运动控制、导航规划、具身大模型，直接对应蚂蚁灵波挑战赛的具身操作能力 |
| 生成式人工智能 | 提供生成模型、Transformer、扩散模型、大语言模型，支撑具身大模型与智能车的生成式感知/决策能力 |
| 自动驾驶理论、算法与实践 | 提供传感器、场景感知、定位、行为决策、运动规划、控制、仿真测试，直接对应 IVFC2026 智能车能力 |

## 四、知识图谱的构建与管理

本知识库使用 graphify 构建为可查询的知识图谱。

- **构建方式**：将本 `knowledge-base/` 目录作为语料输入 graphify，生成 `graph.json`（结构化图谱数据）、`graph.html`（交互式可视化）、`GRAPH_REPORT.md`（审计报告）。
- **边标签含义**：`EXTRACTED` 表示关系直接来自语料原文，`INFERRED` 表示由 graphify 解析推断。每条边可追溯来源。
- **查询方式**：用 `graphify query "<问题>"` 在图谱上做 BFS 遍历，用 `graphify path "A" "B"` 追踪两概念间的最短路径，用 `graphify explain "X"` 解释某节点及其邻居。
- **新赛事扩展**：在 `01-赛事目标/` 新增赛事文件，在 `03-MECE能力体系/` 新增能力域，在 `04-赛事知识映射/` 新增映射文件，重新运行 graphify 即可将新赛事知识并入图谱，既有节点与边不受影响。

## 五、学习路径建议

按「先习而后学」的次序，建议的实际学习路径：

1. **先参赛（习）**：直接进入赛事目标，理解赛题、平台、评分口径，动手尝试最小可运行方案，在真实约束中发现问题。
2. **再补学（学）**：根据遇到的问题，在图谱中按「赛事 → 能力域 → 知识模块」路径找到所需知识，精准学习六本教材中的对应模块。
3. **验证迭代**：学后回到赛事中验证，检验知识是否真正解决问题，形成「习—学—验」闭环。
4. **扩展新赛事**：当新赛事出现，重复步骤 1-3，利用图谱的可扩展接口补充新能力域与知识模块。
