# IVFC2026 · 中国智能车未来挑战赛

## 一、赛事概况

- **全称**：开放物理世界智能体与能力边界挑战赛暨 2026 中国智能车未来挑战赛（IVFC2026）。
- **渊源**：源于国家自然科学基金委员会 2008 年「视听觉信息的认知计算」重大研究计划，已举办十五届，累计 300+ 车队。
- **赛程**：12 月上中旬线上预赛；2026-12-26 现场决赛与演示。
- **官网**：https://ivfc.caa.org.cn/

## 二、赛事平台（CARLA 0.9.16）

本赛事基于 CARLA 0.9.16 仿真环境开展自动驾驶算法公开测试。平台三部分：

- **Controller**：测试管理——查询场景、启动测试、查看预览并保存结果。
- **Host**：仿真环境——CARLA、地图、1300 个公开场景、传感器/导航/任务信息。
- **Client**：算法容器——运行参赛队算法，通过 SDK 获取环境信息并返回驾驶控制指令。

**标准车**：IVFC 定制林肯 MKZ 仿真车型，14 个实体传感器：RGB 相机 ×6（前后左右）、毫米波雷达 ×5、激光雷达 ×1、GNSS ×1、IMU ×1、车速 ×1。

**接口**：API v2；固定传感器配置标识 `fixed-rig-v1`；仿真步长 / 正常算法请求间隔 / 实体传感器采样周期均为 0.05 s（20 Hz）。

**场景分级**：场景编号含 L1–L5 五个难度等级。

## 三、本地测试环境要求

- Linux x86_64；Python 3.8+；Docker Engine；NVIDIA 驱动 + NVIDIA Container Toolkit。
- 参考配置：CPU ≥12 逻辑核；内存 ≥32 GiB；NVIDIA GPU（支持图形与 Vulkan）；磁盘 ≥100 GiB。

## 四、算法接入接口

- Agent 类可无参数构造，SDK 按 Reset → 多次 Step → Close 调用。
- 常用 Controller 参数：`--environment-image`、`--agent-image`、`--case`、`--sim-gpu`、`--agent-gpu`、`--agent-cpus`、`--agent-memory`、`--view`、`--mode`、`--max-cases`、`--output`。
- 超时：`--startup-timeout`、`--step-timeout`、`--timeout`。

## 五、评分口径

| 项 | 值 | 含义 |
|---|---|---|
| settings（赛段） | pre（线上预赛）、final（现场决赛） | 两个赛段各自计通过率 |
| tasks（任务） | L1、L2、L3、L4、L5 | 官方场景难度等级 |
| attempts_per_task | 不限 | 每级按实际运行场景数填报，可多次迭代后整体更新提交 |

- **任务通过率** = successes / attempts（未运行等级 = 0）。
- **赛段均分** = 该赛段 5 个等级通过率的平均。
- **s_total** = 两个赛段均分的平均（榜单排名键）。
- 每个单元格 `{"attempts": N, "successes": M}`：N = 实际运行过的场景总数，M = 通过数（以本地 Controller 报告为准）。
- 榜单取每条路线的最优 s_total；提交即锁定，不可覆盖、不可删除。

## 六、对参赛者的能力要求（赛事牵引的能力域）

IVFC2026 要求参赛者具备以下能力域（与 `03-MECE能力体系/` 对应）：

1. **仿真环境与系统接入能力**：理解 CARLA 仿真平台、Docker 容器、SDK 接口，能完成算法接入与运行。
2. **多传感器感知能力**：融合 14 路传感器（相机、毫米波雷达、激光雷达、GNSS、IMU），完成交通场景感知与理解。
3. **定位与地图能力**：在仿真环境中完成空间定位，利用高精度地图先验。
4. **行为决策能力**：根据感知与地图信息，生成安全可行的行为策略。
5. **运动规划与控制能力**：在复杂交通场景中产生安全有效的运动轨迹并执行车辆控制。
6. **仿真测试与验证能力**：理解仿真、测试与验证技术，完成场景运行、结果保存与通过率计算。
